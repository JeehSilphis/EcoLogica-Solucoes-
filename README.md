# EcoLogica-Solucoes-
projeto acadêmico que visa criar um site MVP de 10 páginas com tema de sustentabilidade e impacto social. A entrega parcial (primeira etapa) abrange a Home (HTML/CSS com semântica e acessibilidade), Escopo do Projeto e Apresentação (PPT). A entrega final exige todas as 10 páginas interligadas, documentação completa e a hospedagem na nuvem Railway.
